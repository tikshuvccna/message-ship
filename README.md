# ספינת המסרים (Message Ship)

משחק דפדפן בסגנון Ship of Fools ללימוד **פרוטוקולים ומודלים** (OSI, TCP/IP, כימוס) לכיתה י״א, מגמת תקשוב.
מפליגים על ספינת דואר, נושאים כדורי אור מתויגים בחוקי התקשורת אל התותחים, מנקים יצורי "רעש", ובמגדלורים לומדים שלושה שיעורים עם חידון ומשחקון בשלוש רמות. בסוף מחכה הקראקן הגלום.

- שחק: https://tikshuvccna.github.io/message-ship/
- פיתוח: `npm install`, `npx vite --port 5201`, בדיקות `npx vitest run`, טיפוסים `npx tsc --noEmit`.
- בנייה: `npm run build`. הורדה לא מקוונת: `python offline/make_offline.py` (אחרי build).
- מסמכי תכנון: `specs/message-ship/` (בריפו הראשי של הפרויקט, לא כאן): `00_DESIGN.md`, `01_CONTRACT.md`, `02_CUTSCENES.md`, `03_MUSIC_AND_VOICE.md`.
- אמנות: `art/README.md` (Blender 5.2, רינדור טון, אטלסים ב-`public/assets`).
